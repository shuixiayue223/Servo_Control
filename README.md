# Servo Control

STM32F103 small servo controller project for the H-bridge board.

## Project

- `Control_s/`: Keil/CubeMX firmware project for the small servo board
- `servo_control_node1.dbc`: CAN database for node ID 1
- `docs/CHANGELOG_CN.md`: changes made during debugging and baseline notes

The repository does not contain a complete pre-change snapshot. The original local workspace had no Git history and no full source backup, so the change log identifies the files and behaviors that were modified without labeling an unrelated large-board project as the old version.
