# 变更说明

## 当前版本

当前版本对应本地小舵机板工程 `Control_s`，主要包含：

- 小舵机板 ADC 扫描调整为 4 路，移除第二路 MOS 温度采样。
- `temp2` 在控制层沿用 `temp1`，兼容原有双温度逻辑。
- CAN 电流、速度、位置、状态和调试遥测协议保留，并提供 node ID 1 的 DBC。
- CAN 超时采用软停机，不锁存 CAN 超时故障，便于摇杆换向。
- 速度估计窗口调整为 50ms。
- 非电流模式增加电流目标变化率限制，减小低速速度环冲击。
- 速度模式增加低速起步电流补偿。
- 电流零点增加低电流条件下的慢速漂移跟踪。

## 改动前版本

本地工程在整理到 GitHub 之前没有 Git 提交历史，也没有完整的源代码备份。因此无法可靠恢复并提交一份完整的改动前版本。

旁边的 `Control` 和 `大舵机控制` 是其他工程或硬件版本，不能作为小舵机板的准确改前版本。
